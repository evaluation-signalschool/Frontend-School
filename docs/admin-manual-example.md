# คู่มือการปฏิบัติงานสำหรับผู้ดูแลระบบ (Admin Operation Manual)
**ระบบแจ้งผลการเรียนและแบบประเมินออนไลน์ — โรงเรียนทหารสื่อสาร กรมการทหารสื่อสาร**

---

## สารบัญภาพรวมเล่มคู่มือผู้ดูแลระบบ
- **บทที่ 1: การเข้าสู่ระบบและระดับสิทธิ์การใช้งาน (Authentication & Roles)**
- **บทที่ 2: การจัดการข้อมูลพื้นฐาน (Basic Information Setup)**
  - 2.1 การจัดการหลักสูตรและรายวิชา (`/admin/addcourse`)
  - 2.2 การจัดการข้อมูลนักเรียนและการนำเข้าด้วยไฟล์ Excel (`/admin/addstudent`) *(บทตัวอย่างละเอียด)*
  - 2.3 การอนุมัติคำร้องขอแก้ไขโปรไฟล์และหลักฐานเปลี่ยนยศ (`/admin/profile-approvals`)
  - 2.4 การจัดการข่าวสารและประกาศ (`/admin/news-management`)
- **บทที่ 3: การจัดการแบบประเมินออนไลน์ (Evaluation Management)**
  - 3.1 การสร้างและตั้งค่าแบบประเมิน (`/admin/form`)
  - 3.2 การตรวจสอบข้อมูลผลการตอบแบบประเมิน (`/admin/form-view`)
- **บทที่ 4: การจัดการคะแนนและผลการเรียน (Grading & Attendance)**
  - 4.1 การบันทึกคะแนนดิบรายวิชา (`/admin/scoremanagement`)
  - 4.2 การตรวจสอบสถานะการส่งคะแนนของอาจารย์ (`/admin/score-submission`)
  - 4.3 การบันทึกร้อยละเวลาฝึกอบรม เวลาสอบ และความประพฤติ (`/admin/training-exam-time`)
  - 4.4 ตารางคะแนนรวมและเกรดเฉลี่ยสะสม Master Grid (`/admin/classoverview`)
- **บทที่ 5: การจัดลำดับผลการเรียนและระบบ Tie-Breaking (`/admin/ranking`)** *(บทตัวอย่างละเอียด)*
- **บทที่ 6: การเลือกลงหน่วยและการบริหารโควตา (`/admin/unit-selection`)** *(บทตัวอย่างละเอียด)*
- **บทที่ 7: การออกเอกสารสำคัญทางการและการสรุปผลการฝึกอบรม**
  - 7.1 การออกใบทรานสคริปต์ขนาด A4 และระบบ Batch Print (`/admin/transcript`)
  - 7.2 การออกใบประกาศนียบัตร (`/admin/certificate`)
  - 7.3 การจัดการบทสรุปผลการฝึกอบรมจากสถิติจริง (`/admin/training-summary`)
- **บทที่ 8: การบริหารความปลอดภัยและบันทึกประวัติการใช้งาน (Security & Audit Logs)**
  - 8.1 การจัดการผู้ดูแลระบบ (Admin Users Management)
  - 8.2 ประวัติการทำงานและกิจกรรมย้อนหลัง (Activity Logs)

## วงรอบการปฏิบัติงาน 5 ช่วงเวลาตามรุ่นการศึกษา (Admin Operational Lifecycle)

1. **ช่วงที่ 1: ก่อนเปิดรุ่น (Pre-Course Setup)**
   - เพิ่มหลักสูตรและรุ่นใหม่
   - นำเข้ารายชื่อนักเรียนด้วยไฟล์ Excel (.xlsx)
   - ผูกรายวิชาและกำหนดอาจารย์ผู้สอน
2. **ช่วงที่ 2: ระหว่างการเรียนการสอน (In-Training Operations)**
   - เปิดระบบให้นักเรียนทำแบบประเมินผู้สอน
   - ตรวจสอบและอนุมัติคำร้องขอแก้ไขโปรไฟล์ / แนบไฟล์คำสั่งเปลี่ยนยศ
3. **ช่วงที่ 3: สิ้นสุดการสอบและประมวลผล (Grading & Rankings)**
   - บันทึกคะแนนดิบรายวิชา
   - บันทึกร้อยละเวลาฝึกอบรม (0-100%) เวลาสอบ (0-100%) และคะแนนความประพฤติ
   - ประมวลผลจัดอันดับที่ 1 ถึง N พร้อมใช้ระบบ Tie-Breaking ปลดล็อคคะแนนเท่ากัน
4. **ช่วงที่ 4: การเลือกลงหน่วย (Unit Selection - เฉพาะ นนส.ทบ. และ ช่างอิเล็กทรอนิกส์)**
   - ตั้งค่าโควตาหน่วยบรรจุ
   - เปิดจอ Fullscreen ฉายขึ้นจอประชุม
   - บันทึกผลการเลือกลงหน่วยตามอันดับคะแนน 1 ถึง N
5. **ช่วงที่ 5: สำเร็จการศึกษาและปิดรุ่น (Graduation & Documentation)**
   - พิมพ์ระเบียบแสดงผลการฝึกอบรม (Transcript A4) และใบประกาศนียบัตร
   - ประมวลผลร่างบทสรุปผลการอบรมจากข้อมูลสถิติจริงของระบบเพื่อเผยแพร่

## ตัวอย่างเนื้อหาเจาะลึก: บทที่ 2.2 การจัดการข้อมูลนักเรียนและการนำเข้า Excel

### ขั้นตอนการนำเข้าไฟล์ Excel (.xlsx)
1. เข้าเมนู **"ข้อมูลพื้นฐาน"** > **"จัดการข้อมูลนักเรียน"** (`/admin/addstudent`)
2. เลือก **"หลักสูตร"** และ **"รุ่นการศึกษา"** ที่ต้องการนำเข้า
3. สลับไปยัง **"แท็บ 3: นำเข้าด้วยไฟล์"**
4. คลิกดาวน์โหลดไฟล์ Template หรือเตรียมไฟล์ Excel ตามโครงสร้างคอลัมน์มาตรฐาน:

| ชื่อคอลัมน์ Excel | ตัวอย่างข้อมูล | ชนิดข้อมูล | คำอธิบายและการตรวจสอบ (Validation) |
| :--- | :--- | :--- | :--- |
| **student_code** | 67001 หรือ 01 | Text (ข้อความ) | เลขประจำตัวนักเรียน หรือลำดับที่นั่งเรียน (ห้ามซ้ำกันในรุ่น) |
| **rank_name** | ส.อ., จ.ส.ต., นาย | Text | ยศหรือคำนำหน้าชื่อ |
| **first_name** | สมชาย | Text | ชื่อจริง |
| **last_name** | รักชาติ | Text | นามสกุลจริง |
| **id_card** | 1409900123456 | Text (13 หลัก) | เลขบัตรประชาชน สำหรับใช้เชื่อมต่อกับ Google Sign-In |
| **original_affiliation** | ส.พัน.๑ | Text (ตัวเลือก) | สังกัดเดิมของนักเรียน |

5. ลากไฟล์ `.xlsx` มาวางในกล่องอัปโหลด ระบบจะแสดงผลตัวอย่างรายชื่อและจำนวนนายที่ตรวจพบ
6. กดปุ่ม **"ยืนยันการนำเข้าข้อมูลสู่ระบบ"**

> **ข้อควรระวัง:** คอลัมน์ `student_code` และ `id_card` ต้องกำหนด Format ใน Excel เป็น **Text (ข้อความ)** เสมอ หากตั้งเป็นตัวเลข โปรแกรม Excel อาจตัดเลข 0 ตัวหน้าทิ้ง ทำให้นักเรียนล็อกอินไม่ผ่าน

## ตัวอย่างเนื้อหาเจาะลึก: บทที่ 5 การจัดลำดับผลการเรียนและ Tie-Breaking

### กลไกการจัดอันดับและการชี้ขาด
1. เข้าเมนู **"คะแนนและผลการเรียน"** > **"จัดลำดับผลการเรียน"** (`/admin/ranking`)
2. เลือกรุ่นที่ปิดการบันทึกคะแนนเรียบร้อยแล้ว ระบบจะประมวลผล GPA และคะแนนรวมทั้งหมด
3. ตรวจสอบ **"กล่องเด่นพิเศษ: ผู้ครองโล่รางวัลเกียรตินิยม อันดับ 1, 2, 3 (กรอบทอง)"** ด้านบน
4. **การปลดล็อคคะแนนเท่ากัน (Tie-Breaking Panel):**
   - หากผู้มีสิทธิ์ชิงโล่เกียรตินิยมมีคะแนนเท่ากัน ให้เปิดแผง Tie-Breaking
   - ติ๊กเลือก **"รายวิชาหลักที่มีน้ำหนักสำคัญ"** (เช่น วิชาภาคทฤษฎีเฉพาะเหล่า)
   - กดปุ่ม **"คำนวณอันดับใหม่"** ระบบจะนำคะแนนวิชาที่เลือกมาใช้ตัดสินอันดับทันที
5. **การปรับลำดับด้วยตนเอง (Manual Override):**
   - หากคณะกรรมการมีมติเป็นเอกฉันท์ สามารถกดปุ่มลูกศร `⬆️` หรือ `⬇️` เพื่อสลับอันดับได้โดยตรง โดยระบบจะแสดงป้ายกำกับว่า *"มีการปรับด้วยมือ"*

## ตัวอย่างเนื้อหาเจาะลึก: บทที่ 6 การเลือกลงหน่วยและการบริหารโควตา

### สูตรการคิดคะแนนเลือกลงหน่วย
$$\text{คะแนนสุทธิ 100\%} = \text{คะแนนวิชาการ (80\%)} + \text{คะแนนความประพฤติ (20\%ใหม่)}$$

### ขั้นตอนการดำเนินการเลือกลงหน่วย
1. เข้าเมนู **"เลือกลงหน่วย"** (`/admin/unit-selection`)
2. ตั้งค่าจำนวนอัตราใน **"แผงกำหนดสิทธิ์เลือกลงหน่วย (Quota Allocation Panel)"** ให้ครบตามยอดนักเรียน
3. คลิกปุ่ม **"เปิดโหมดเต็มจอ (Fullscreen)"** เพื่อขยายตารางเต็มจอสำหรับฉายโปรเจกเตอร์ในห้องประชุม
4. เรียกนักเรียนตามลำดับอันดับที่ 1 ลงมา และพิมพ์เลือกหน่วยในช่องเลือกลงหน่วย (มีระบบ Autocomplete ช่วยค้นหา)
5. กล่อง **"Units Quota Tracker"** ด้านบนจะหักยอดโควตาคงเหลือแบบ Real-time ทันที
6. เมื่อเสร็จสิ้น สามารถกด **"พิมพ์เอกสารสรุปผลการเลือกลงหน่วย"** เพื่อนำเสนอผู้บังคับบัญชาลงนาม
